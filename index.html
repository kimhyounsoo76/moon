📍 촬영 뒤 달 위치 표시

기준 사진을 쓸 때, 찍은 사진 속 달의 자리를 어떻게 정할지 골라요. '눌러 확인'은 사진이 바로 떠서 달을 톡 누르고(짐작 자리가 미리 표시됨), '자동 저장'은 묻지 않고 나침반 짐작 자리로 저장한 뒤 기록 탭에서 📍로 고쳐요. 자동 저장은 나침반이 있는 기기에서만 돼요.

🧭 나침반 보정

관측 화면에서 달을 십자선 가운데에 맞춘 뒤 🎯 버튼을 누르면, 그 순간의 달 위치(계산값)로 나침반이 자동 보정돼요. 휴대폰 나침반은 10° 안팎 틀릴 수 있어 관측 시작 때 한 번 해 두면 좋아요.

💾 자료

📖 사용 안내
  1. 카메라·나침반은 https 주소(예: GitHub Pages)나 앱으로 설치했을 때 켜져요. 파일을 바로 열면 사진 파일·손 기록만 돼요.
  2. 아이폰·아이패드는 관측 화면의 '나침반 켜기'를 눌러 센서를 허용해 주세요.
  3. 관측 순서(교과서 방식): ① 늘 같은 자리에 서서 ② 📌로 기준 사진(학교 건물·나무가 들어가게, 달은 화면 왼쪽에)을 찍고 ③ 화면에 겹쳐 보이는 노란 윤곽에 건물을 맞춰 📸 ④ 사진 속 달을 손가락으로 눌러 표시(설정에서 '자동 저장'으로 바꾸면 이 단계가 생략돼요) ⑤ ⏱ 알림으로 30분~1시간마다 반복 ⑥ 기록 탭에서 달의 길·기록지 만들기.
  4. 기준 사진을 찍을 때와 같은 방향(세로/가로)으로 휴대폰을 들어요. 달이 기준 화면 밖으로 나가면 📌로 새 기준을 찍어요.
  5. 달을 십자선에 맞추고 🎯를 누르면 나침반 오차가 보정돼요(기준 사진 찍기 전에 한 번).
  6. 삼각대로 고정하고 ⏱ 자동 촬영을 켜 두면, 나중에 겹쳐 보기로 달이 지나간 길이 한 장에 나와요.
  7. 달이 너무 밝게 찍히면 🔍 확대 슬라이더(지원 기기)로 당겨서 찍어 보세요.
  8. 기록은 이 기기 안에만 저장돼요. 다른 기기로 옮길 땐 백업 파일을 쓰세요.
